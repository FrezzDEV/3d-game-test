# Floating Isles — 3D Island Prototype

Горизонтальный браузерный прототип главного меню фэнтези-стратегии: парящий остров, компактные воксельные здания и интерфейс управления базой.

## Запуск

Проект использует Three.js как ES-модули с CDN. Открой репозиторий через статический хостинг или запусти локальный сервер:

```bash
python -m http.server 8000
```

Открой `http://localhost:8000`. Не используй `file://`: браузер может блокировать ES-модули.

## Управление

- Левая кнопка мыши по зданию — выбрать.
- Перетаскивание выбранного здания — переместить.
- Кнопка «Строить» — открыть каталог.
- Выбери здание, затем нажми на свободное место острова.
- Колесо мыши — масштаб.
- Правая кнопка мыши — управление камерой.
- В карточке выбранного здания нажми «Экспорт GLB», чтобы скачать отдельную модель.

## Как получать 3D-здания

Каждое здание — самостоятельный `THREE.Group`, создаваемый функцией `createBuilding(id)` в `src/buildings.js`.

1. Добавь описание в массив `BUILDINGS`.
2. Добавь геометрию в функцию `makeBuilding(def)`.
3. Выбери здание на острове.
4. Нажми «ЭКСПОРТ GLB».
5. Импортируй скачанный файл в Blender, Godot или другой 3D-движок.

Модели создаются из кубов и экспортируются отдельно от острова и интерфейса. Так можно постепенно собрать библиотеку из 50+ зданий.

## Структура

```
index.html
styles.css
src/
  main.js       # сцена, управление, интерфейс, GLB export
  world.js      # остров, окружение и стартовая расстановка
  buildings.js  # каталог и геометрия зданий
```

## Ограничения текущего прототипа

- Ресурсы демонстрационные, серверного сохранения пока нет.
- Магазин, инвентарь, задания и экспедиции пока представлены интерфейсными заглушками.
- Размещение работает по сетке; проверка столкновений и сохранение построек — следующий этап.
- Террейн использует InstancedMesh для уменьшения количества draw calls на мобильных устройствах.
