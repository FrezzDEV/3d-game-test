# Floating Isles — 3D Island Prototype

Горизонтальный браузерный прототип: парящий воксельный остров, свободное размещение зданий и интерфейс управления базой.

## Запуск

```bash
python -m http.server 8000
```

Открой `http://localhost:8000`. Не используй `file://`: браузер может блокировать ES-модули.

## Управление

- Выбери здание в каталоге после нажатия «Строить».
- Веди курсор или палец по острову: полупрозрачный зелёный призрак означает, что место подходит; красный — что размещение запрещено.
- Нажми/кликни по острову, чтобы подтвердить постройку.
- Перетаскивание мышью/пальцем больше 4 пикселей считается движением камеры, а не подтверждением.
- Колесо мыши — масштаб; правая кнопка мыши — управление камерой.
- Выбери готовое здание, чтобы открыть карточку и экспортировать его в GLB.

## Система размещения

- `src/world.js` формирует `surfaceMap` с высотой верхней клетки для каждого координатного ключа `"x,z"`.
- `topSurfaceMeshes` — отдельные InstancedMesh верхних поверхностей травы, используемые raycaster.
- `src/main.js` переводит pointer-координаты в локальные координаты острова, привязывает их к сетке 0.72 и показывает `ghostGroup`.
- `canPlaceAt(gx,gz)` проверяет границы, ровную площадку 3×3, деревья и существующие здания.
- Подтверждение списывает стоимость здания в золоте и добавляет модель внутрь главной группы острова.
- Остров плавно движется по синусоиде; здания и поверхность перемещаются вместе с ним, поскольку являются дочерними объектами одной группы.

## Как добавлять и экспортировать здания

Каждое здание — самостоятельный `THREE.Group`, создаваемый функцией `createBuilding(id)` в `src/buildings.js`.

1. Добавь описание здания в массив `BUILDINGS`.
2. Добавь его геометрию в `makeBuilding(def)`.
3. Выбери здание в каталоге и размести на острове.
4. Выбери модель и нажми «ЭКСПОРТ GLB».
5. Импортируй GLB в Blender, Godot или другой 3D-движок.

Модели экспортируются отдельно от острова и интерфейса. Это позволяет наращивать библиотеку из 50+ зданий.

## Структура

```
index.html
styles.css
src/
  main.js       # сцена, размещение, проверка, анимация и GLB export
  world.js      # остров, surfaceMap, верхние поверхности и стартовая расстановка
  buildings.js  # каталог и геометрия зданий
```

## Пока не реализовано

- Сохранение построек между перезапусками и серверная синхронизация.
- Полная экономика производства ресурсов.
- Перемещение уже построенного здания через отдельную кнопку.
- Канатные дороги и вагонетки для удалённых целевых островов.
- Магазин, инвентарь, задания и экспедиции пока являются интерфейсными заглушками.
